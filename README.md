# 2D Unity Game / Test Case Project 

Selamlar! Bu repo, Unity ile geliştirdiğim 2D mobil tabanlı oyun projemin kaynak kodlarını barındırıyor. Geliştirme sürecinde özellikle mobil uyumluluk, dokunmatik kontroller, ganimet mekanikleri ve versiyon kontrolü (Git/GitHub) üzerine odaklandım.

##  Projede Neler Var?
* **Mobil Kontroller:** Yeni Unity Input System kullanılarak hem bilgisayar (fare/klavye) hem de telefon (dokunmatik ekran) uyumlu pürüzsüz hareket mekaniği.
* **Gittikçe Zorlaşan Seviyeler:** Oyun ilerledikçe artan zorluk seviyeleri ile dinamik bir oyun deneyimi.
* **Blok Kırma & Roket Kazanma:** Oyun içinde blokları kırdıkça roket kazanma sistemi ve ilerleme mekanikleri.
* **Ganimet Sistemi:** Oyun içinde toplanabilir objeler (collectible itemlar) ile oyuncuya avantaj sağlayan dinamik bir mekanik.
* **Boss Savaşları:** Belirli seviyelerde devreye giren boss savaşları ve dinamik roket/engel sistemleri.
* **UI Düzenlemeleri:** Farklı ekran çözünürlüklerine uyum sağlayabilen Canvas ve arayüz yerleşimleri.

##  Kullanılan Teknolojiler & Araçlar
* **Oyun Motoru:** Unity 6 (6000.5.6f1)
* **Dil:** C#
* **Versiyon Kontrolü:** Git & GitHub

##  Kurulum ve Test
Eğer projeyi kendi bilgisayarınızda açmak ve test etmek isterseniz:
1. Projeyi klonlayın veya indirin.
2. Unity Hub üzerinden **Unity 6** sürümüyle projeyi açın.
3. `Assets/Scenes` klasörünün altındaki `StartScene` ile oyunu başlatabilirsiniz.
